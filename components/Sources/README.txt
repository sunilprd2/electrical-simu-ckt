SimElectro — Sources Library (Phase 1)

This archive contains the nine source/terminal SVG files supplied for the SimElectro project.
The SVG root dimensions have been normalized and a viewBox added to support consistent browser scaling.
The artwork itself has not been redesigned.

Contents:
- Sources/: 9 SVG files
- sources-manifest.json: component names and relative paths

Integration note:
Use the relative file paths in sources-manifest.json from the website root, or update them to match your app's asset-loading convention.
This is an asset pack only; it does not include or modify the website, library renderer, drag/drop, wiring, or simulation code.
