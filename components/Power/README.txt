Electrical Simu CKT — Power Components
=====================================

This folder contains individual SVG files for the Power/Sources category.

Included components:
- 01 DC Negative (01_DC_Negative.svg)
- 02 DC Positive (02_DC_Positive.svg)
- 03 Earth Ground (03_Earth_Ground.svg)
- 04 N Terminal (04_N_Terminal.svg)
- 05 L1 Terminal (05_L1_Terminal.svg)
- 06 L2 Terminal (06_L2_Terminal.svg)
- 07 L3 Terminal (07_L3_Terminal.svg)
- 08 PE Terminal (08_PE_Terminal.svg)
- 09 Three Phase L1 L2 L3 (09_Three_Phase_L1_L2_L3.svg)
- 10 Three Phase Neutral (10_Three_Phase_Neutral.svg)
- 11 Three Phase Neutral PE (11_Three_Phase_Neutral_PE.svg)
- 12 AC/DC Power Supply V1 (12_ACDC_Power_Supply_V1.svg)
- 13 AC/DC Converter V2 (13_ACDC_Converter_V2.svg)
- 14 DC Supply V3 (14_DC_Supply_V3.svg)
- 15 Generator GS3 (15_Generator_GS3.svg)

Each SVG remains a separate file. The SVGs include terminal markers with data-terminal-id attributes where provided. The website's component loader must register these files and map the terminal IDs to the editor's wiring model before they appear in the toolbar or can be wired interactively.

This folder was added without deleting the existing assets/symbols, power-symbols, power-original, or power-originals folders.
