# Original POWER SVG assets

This ZIP includes the existing ELECTRICAL SIMU CKT project plus the 16 individual SVG files uploaded in this turn. Their artwork bytes are preserved unchanged under `assets/symbols/power-originals/`; their uploaded filenames are recorded in `symbol-library.json`.

The archive `MY SIMURELAY BACKUP.rar` previously listed a `gemini-svg (12).svg`, but that file was not included in the individual uploads available for this build. It has not been recreated or substituted.

These assets are catalogued as Power Supply library entries. The current toolbar has its own interactive POWER symbol definitions, so this package does not claim the original artwork has replaced every live toolbar drawing. Please test locally before deploying to GitHub Pages.
